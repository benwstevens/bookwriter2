# This folder is the bookwriter2 repo

If the user wants to set it up ("set up the book generator", "set me up", "install this"), or wants a book ("write me a book about...", "run the book pipeline"): read `README.md` in full and follow it. The section "For the model" has the two interviews and what to build. Nothing is spent on the API without the person's explicit go in the conversation, after they have seen the dry-run estimate.

If the user is maintaining the tool itself: the "For maintainers" section of `README.md` has the repo map, the command reference, the settings file, and the known issues.
